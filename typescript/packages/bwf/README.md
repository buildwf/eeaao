# @builtbyfriends/realtime-bwf

Zero-setup eeao for bwf: a Vite plugin, one middleware file, live queries and the data layer hookup.

It's part of [Realtime](https://github.com/builtbyfriends/realtime), a procedure builder for Cloudflare Workers.

```sh
npm install @builtbyfriends/realtime-bwf
```
